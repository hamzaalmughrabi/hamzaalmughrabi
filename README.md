## 📌 Featured Engineering Projects

### 🏎️ [AI Race Engineering & Motorsport Telemetry Platform](https://github.com/hamzaalmughrabi/AI-Race-Engineering-and-Motorsport-Telemetry-Platform)
*Production-grade high-frequency telemetry analytics and 8-agent cognitive assistant modeled after modern Formula 1 trackside operations.*
- **Spatial Grid Synchronization**: 1-meter spatial grid resampling via PCHIP cubic Hermite interpolation, aligning asynchronous multi-driver telemetry streams ($10\text{--}50\text{ Hz}$) with sub-millisecond precision.
- **Hierarchical Attribution Engine**: Decomposes lap deltas across Timing Sectors, Track Segments, and Corner micro-phases (Braking, Entry, Apex, Exit) with strict energy/time conservation ($\sum \Delta t = \Delta t_{\text{lap}} \pm 1\text{ms}$).
- **Evidence-First Multi-Agent Architecture**: 8-agent LangGraph system with an adversarial validator enforcing zero token hallucination where all strategic recommendations cite verified numerical telemetry evidence.
- **Interactive Engineering Workstation**: WebGL track map with continuous $d\Delta t/ds$ rate heatmaps, linked 6-channel crosshair scrubbing, and automated corner deep-dives.

### 🛸 Autonomous Drone-Swarm Command & Control (C2) Platform
*Mission-critical multi-agent coordination platform executing decentralized path planning and dynamic target allocation.*
- **100x Latency Reduction**: Cut mission-planning path generation latency from $\sim 1{,}000\text{ ms}$ to $\sim 10\text{ ms}$ by redesigning path generation into a two-level hierarchical optimization loop.
- **Multi-Agent Swarm Orchestration**: 5-layer autonomous agent architecture coordinating 10+ simulated UAVs under live constraints, combining YOLOv8 real-time vision, Grey Wolf Optimizer, and Hungarian algorithm task assignment.
- **Real-Time Telemetry Interface**: Execution lockstep protocol and a high-frequency Ground Control Station (GCS) telemetry dashboard in Qt6/QML with cryptographic validation.
